## Tipografía

- **Títulos principales:** Sans-serif bold, similar a **Montserrat Bold** o **Poppins Bold** ("VIAJA MÁS, preocúpate menos")
- **Eslogan script:** Estilo caligrafía/manuscrito, similar a **Dancing Script** o **Pacifico** para "preocúpate menos"
- **Subtítulos:** Sans-serif semibold, similar a Montserrat Medium
- **Cuerpo/texto:** Sans-serif regular, similar a Open Sans o Inter

## Notas para diseño web

- El banner (img_01.jpg) es la referencia visual definitiva — tiene logo, paleta, eslóganes y estructura de serviicios ya definidos.
- El eslógan "VIAJA MÁS, preocúpate menos" es fuerte y puede usarse como hero headline.
- La combinación azul + blanco + verde es la paleta base; rojo/terracota es el acento para logo y CTAs.
- Un serif o script para acentos románticos (lunas de miel) contrastaría bien con el sans-serif corporativo.
